# モデルの前提と確認事項

このシミュレータの数値は、操作と結果の因果関係を体験するための近似です。定数は `src/sim/model.ts` の `K` と各式にまとめてあります。**「要確認」の項目は一般的な値を仮置きしたもので、施設プロトコルに合わせた見直しが必要です。**

## 決定済みの仕様

- 動作環境: Webブラウザ（TypeScript、GitHub Pages）
- 対象: 新人臨床工学技士
- モデル精度: 中程度（集中定数モデル）
- 初回シナリオ: 心停止下CABG ×3
- 送血ポンプ: ローラー／遠心を開始時に選択
- 心筋保護: 血液併用（4:1）／晶質液、順行性のみ／順行性＋逆行性を選択
- 表示言語: 日本語・英語切替

## 患者モデル

| 要素 | 内容 |
| --- | --- |
| 循環 | 動脈（コンプライアンス 1.5 mL/mmHg）と静脈（100 mL/mmHg）の2区画。体血管抵抗はHct・体温・薬剤で変化 |
| 自己心 | CVPに応じた拍出（Frank–Starling）、後負荷、収縮力。遮断中は拍出なし |
| 酸素 | VO₂ = 110 mL/min/m² × 2.2^((T−37)/10)。Fickの式でSvO₂、DO₂iを算出 |
| CO₂ | PaCO₂ = 0.863 × VCO₂ ÷ 有効換気量（人工肺はガス流量 × 0.95） |
| 体温 | 咽頭温（速い）と膀胱温（遅い）の2区画。熱交換器効率 0.5 |
| rSO₂ | 脳血流（自己調節・PaCO₂・Hct・体温）と脳酸素消費から算出 |
| 抗凝固 | ヘパリン半減期 100分、感受性に個人差。ACTは体温・希釈で延長 |
| 電解質・代謝 | K⁺は心筋保護液で上昇。DO₂i不足で乳酸上昇 |

## 採血とCDI（連続血液ガスモニター）

- 採血: 動脈側（人工肺出口）と静脈側（脱血側）を選んで採血し、60秒後に血液ガスの結果が出る（37℃表示）
- 静脈血: PvO₂はSvO₂から逆算、PvCO₂ = PaCO₂ + 灌流量とVCO₂に応じた較差
- CDI: 動脈側（pH・PCO₂・PO₂・K⁺、計算値のHCO₃⁻・BE・SaO₂）、静脈側（SvO₂・Hct・Hb）、DO₂i・VO₂i。センサーに血流がないと表示なし
- CDIのずれ: 開始時に誤差（pH ±0.035、PCO₂ ±4、PO₂ ±30、K⁺ ±0.35、SvO₂ ±3.5、Hct ±2.5）があり、時間とともにゆっくり変動
- 校正: ストア → 採血 → 結果で校正。ストア時の表示値と採血結果の差だけ補正するため、ストアと採血の時刻が離れると誤差が残る
- 体外循環開始後20分以内に校正しないと減点（3点）

## 人工心肺モデル

- ローラー: 流量 = 回転数 × 27 mL/rev。クランプしたまま回すと回路内圧が急上昇
- 遠心: 揚程 = 5×10⁻⁵ × rpm²。後負荷で流量が変わり、低回転でライン開放すると逆流
- 脱血: 落差 30 mmHg、オクルーダー開度と脱血管位置（心臓脱転で低下）に依存
- リザーバー: 初期 800 mL、回路内 600 mL（充填量 計 1400 mL）
